# Loan Risk Analysis & Underwriting Dashboard

An end-to-end Power BI Business Intelligence solution designed to analyze credit risk profiles, evaluate historical loan metrics, and detect core data-driven indicators that impact borrower loan approval and defaults.

## Project Overview
This project simulates real-world underwriting logic using custom data visualizations and advanced data profiling. The goal is to evaluate applicant metrics (such as credit scores, Debt-to-Income ratios, and recent payment histories) to identify risk trends, segment safe vs. high-risk applicants, and protect lending capital from preventable default rates.

## Key Features & Business Insights
* **KPI Tracking:** Monitor vital operational lending metrics including Total Applications, Funded Capital, Average Interest Rates, and Debt-to-Income (DTI) scores.
* **Risk Segmentation:** Break down credit data across FICO score bands, Payment-to-Income (PTI) matrices, and Loan-to-Value (LTV) limits.
* **Good vs. Bad Loan Analysis:** Interactive visual comparisons of baseline approval habits against historically problematic and defaulted accounts.
* **Dynamic Demographic Filters:** Filter granular financial information cleanly by employment length, regional geography, or historical loan purpose.

## Technical Stack
* **Tool:** Microsoft Power BI Desktop
* **Languages:** DAX (Data Analysis Expressions) for complex calculations, Power Query (M) for data modeling and cleaning
* **Architecture:** Optimized star schema data modeling for quick filter response times
